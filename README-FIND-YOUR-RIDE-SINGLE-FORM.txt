DRIVEHUB GH — FIND YOUR RIDE SINGLE-FORM UPDATE

What changed
- Keeps the vehicle fleet cards as the vehicle-selection step.
- Removes the separate date and destination/purpose form blocks beneath the fleet.
- Moves pickup date, return date, destination region, town/exact destination, and trip purpose into the dark premium journey summary.
- The summary is now the main enquiry form and has a clear “Send rental enquiry” action.
- Retains existing IDs and the existing booking submission logic, so the request continues to open a prefilled WhatsApp enquiry to DriveHub GH.
- Rental duration still counts both pickup and return dates as rental days.
- Responsive styling keeps the form usable on mobile.

Files included
- DriveHub-GH-main/find-your-ride.html
- DriveHub-GH-main/styles.css

Install
Replace these two files in the repository at their matching paths, commit and push, and wait for Cloudflare Pages to deploy. Do not upload the ZIP itself as a repository file. This package does not deploy changes automatically.
