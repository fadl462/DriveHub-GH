DriveHub GH — Automatic Authorised Signature

Replace/add these files at the repository root:
- command/app.js (replace existing)
- command/fadl-signature.png (new file)

The supplied signature artwork is applied to the Authorised By area on printed invoices and to the authorised section on every payment receipt generated by Command Centre.

The print routine waits for images to decode before opening the browser print dialog.

After uploading, commit and push to GitHub and wait for Cloudflare Pages deployment. Then test one invoice and one payment receipt.

This package does not change rental, invoice, or payment records.
