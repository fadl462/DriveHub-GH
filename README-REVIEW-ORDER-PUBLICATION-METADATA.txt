DriveHub GH — review order, publication and metadata fix

Updated files only:
- command/app.js: keeps reviews sorted newest-first in every filter and displays submission date/time (Ghana time) in Command Centre metadata.
- index.html: public homepage loads the newest approved reviews from /api/reviews so newly approved reviews can appear publicly. The API intentionally excludes private “What could improve” feedback.

Install these files at the same paths in the DriveHub-GH repository and deploy through Cloudflare Pages. Review submission timestamps are generated by the server in D1; clients are not asked to enter a review date.
