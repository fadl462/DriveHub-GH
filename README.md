# DriveHub GH Premium Multi-Page Website

- `index.html` — Home
- `fleet.html` — Our Fleet
- `experience.html` — The Experience
- `how-it-works.html` — How It Works
- `faqs.html` — FAQs
- `find-your-ride.html` — Rental enquiry

Each menu and footer item opens a dedicated HTML page. The enquiry form opens WhatsApp with details pre-filled; it does not check live availability or confirm bookings. Open `index.html` in a browser or deploy the folder contents to Cloudflare Pages.

The homepage opens with explicit premium self-drive car rental messaging and a rental enquiry panel directly below the hero.
